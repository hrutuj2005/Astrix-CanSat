# 🚀 Mission Objectives — Astrix CanSat

---

# 📌 Mission Overview

The Astrix CanSat mission was developed for the CanSat Competition hosted by Presidency University, Bengaluru.

The project simulates a miniature satellite system capable of collecting, transmitting, and analyzing atmospheric telemetry data during aerial deployment and descent.

The mission combines embedded systems, wireless telemetry, environmental sensing, and aerospace mission simulation into a compact CanSat platform.

---

# 🎯 Primary Mission Objectives

## 1. Safe Aerial Deployment

- Successfully deploy the CanSat from the authorized aerial platform.
- Ensure stable parachute-assisted descent.
- Maintain structural integrity during deployment and landing.

---

## 2. Real-Time Telemetry Transmission

Transmit telemetry data continuously at 1 Hz during descent.

Telemetry parameters include:

- Temperature
- Humidity
- Pressure
- GPS Coordinates
- Altitude
- Battery Status
- RSSI
- IMU Data

---

## 3. Ground Station Communication

- Establish reliable Zigbee-based wireless communication.
- Maintain telemetry reception throughout the mission.
- Decode and visualize incoming telemetry in real time.

---

## 4. Onboard Data Logging

- Store all telemetry data onboard using SD card logging.
- Save telemetry in CSV format for post-flight analysis.
- Ensure data integrity throughout the mission.

---

## 5. Payload Protection

- Protect onboard electronics from vibration and impact.
- Ensure safe landing without payload failure.
- Maintain secure internal mounting of components.

---

# 🛰 Secondary Mission Objectives

- Develop an aerospace-grade embedded system.
- Create a reliable telemetry architecture.
- Improve communication reliability.
- Perform real-time sensor monitoring.
- Simulate real satellite subsystem integration.

---

# 🧠 Engineering Objectives

The project focuses on:

- Embedded systems engineering
- Aerospace mission simulation
- Wireless telemetry systems
- Sensor fusion and monitoring
- Ground station visualization
- Real-time data acquisition
- System integration and testing

---

# 📡 Communication Objectives

The communication subsystem was designed to:

- Operate using Zigbee communication
- Maintain stable telemetry reception
- Minimize packet loss
- Monitor RSSI values during flight
- Support real-time ground station visualization

---

# 📊 Data Collection Objectives

The CanSat system was designed to collect:

| Parameter | Purpose |
|---|---|
| Temperature | Environmental monitoring |
| Humidity | Atmospheric analysis |
| Pressure | Altitude estimation |
| GPS Coordinates | Location tracking |
| IMU Data | Motion analysis |
| RSSI | Communication quality |
| Battery Status | Power monitoring |

---

# 🏁 Mission Success Criteria

The mission is considered successful if:

- The CanSat deploys safely
- Parachute deploys correctly
- Telemetry is transmitted continuously
- Ground station receives valid data
- Telemetry logs are saved successfully
- Payload remains structurally intact after landing
