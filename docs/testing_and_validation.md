# 🧪 Testing and Validation — Astrix CanSat

---

# 📌 Overview

The Astrix CanSat system underwent multiple stages of testing and validation to ensure mission readiness, communication stability, structural reliability, and telemetry integrity.

Testing procedures were performed to evaluate subsystem performance under simulated mission conditions.

---

# 🎯 Testing Objectives

The testing phase focused on validating:

- Sensor accuracy
- Wireless communication reliability
- Telemetry integrity
- Ground station performance
- Structural stability
- Power reliability
- Recovery system effectiveness

---

# 🌡 Sensor Testing

Environmental sensors were tested to validate data consistency and real-time responsiveness.

## Parameters Tested

- Temperature
- Humidity
- Pressure
- GPS Coordinates
- IMU Data

## Validation Goals

- Stable readings
- Real-time updates
- Noise reduction
- Calibration verification

---

# 📡 Communication Testing

The Zigbee telemetry system was tested for stable wireless communication during simulated deployment conditions.

## Communication Validation

- Packet transmission testing
- Packet reception testing
- RSSI monitoring
- Signal stability analysis
- Packet loss monitoring

## Objectives

- Maintain reliable communication
- Ensure continuous telemetry reception
- Validate ground station decoding

---

# 💾 SD Card Logging Validation

The onboard logging subsystem was tested to ensure reliable telemetry storage.

## Logging Tests

- CSV file generation
- Real-time packet logging
- Timestamp validation
- Data integrity verification

## Expected Output

```text
telemetry.csv
```

---

# 🖥 Ground Station Testing

The ground station system was validated for real-time telemetry visualization and monitoring.

## Ground Station Features Tested

- Real-time telemetry display
- Sensor graph plotting
- RSSI monitoring
- CSV data storage
- Communication synchronization

---

# 🔋 Power System Testing

The power subsystem was validated for stable operation throughout the mission duration.

## Power Validation

- Battery voltage monitoring
- Power stability testing
- Load testing
- Runtime verification

---

# 🪂 Recovery System Testing

The parachute recovery system was tested to ensure safe descent and payload protection.

## Recovery Objectives

- Stable parachute deployment
- Controlled descent
- Reduced landing impact
- Payload protection

---

# 🏗 Structural Integrity Testing

Structural testing was performed to validate mechanical reliability.

## Structural Validation

- Component mounting inspection
- Vibration resistance testing
- Wiring stability verification
- Payload protection analysis

---

# 📊 Telemetry Verification

Telemetry packets were verified for proper formatting and successful transmission.

## Validation Areas

- Packet structure verification
- Timestamp accuracy
- Sensor value consistency
- Ground station decoding accuracy

---

# 🚀 Mission Simulation Testing

Integrated system testing was conducted to simulate mission conditions.

## Mission Validation Goals

- Full subsystem synchronization
- Stable telemetry operation
- Reliable communication
- Successful onboard logging
- Ground station visualization
