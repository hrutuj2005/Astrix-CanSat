# 📅 Project Timeline — Astrix CanSat

---

# 📌 Overview

This document outlines the development timeline followed during the design, implementation, testing, and deployment preparation of the Astrix CanSat project.

The project workflow was divided into structured engineering phases to ensure systematic subsystem integration, testing, and mission readiness.

---

# 🚀 Project Development Phases

The development process was divided into the following stages:

1. Mission Planning
2. System Design
3. Hardware Development
4. Embedded Software Development
5. Communication System Integration
6. Ground Station Development
7. Testing and Validation
8. Final Integration
9. Competition Preparation
