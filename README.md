# 🚀 Astrix CanSat    ![Astrix CanSat](images/logo/Astrix_Logo.jpg)

An award-winning autonomous CanSat developed for aerospace mission simulation, real-time telemetry transmission, environmental sensing, and ground station visualization.

---

# 📌 Overview

Astrix CanSat was designed and developed for the CanSat Competition hosted by Presidency University, Bengaluru.

The project simulates a miniature satellite system capable of collecting atmospheric data during descent while transmitting real-time telemetry to a ground station using Zigbee communication.

The CanSat integrates embedded systems, sensors, wireless communication, onboard data logging, and live monitoring systems into a compact aerospace platform.

# 📡 Mission Profile

The CanSat was deployed from an aerial platform and designed to:

- Collect environmental data
- Transmit telemetry at 1 Hz
- Log telemetry data to onboard storage
- Maintain stable communication with the ground station
- Achieve safe descent using a parachute system
- Protect payload integrity during landing
